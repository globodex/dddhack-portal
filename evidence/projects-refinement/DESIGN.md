# Showcase specification

Match the accepted Team Studio paper/ink, name scale and restrained saved-team washes. Use a clear project identity with its real logo, title, summary and team, one detail link, then separate existing vote/comment controls. Two columns on broad desktop, one column on tablet/mobile. Retain natural document scrolling on short screens.

For a genuinely empty collection, show one purposeful warm panel with a compact existing expression dot, factual eligibility sentence and an actor-appropriate solid action. Omit the empty search box. A query that has zero matches is a different state: keep its search, show Clear search, preserve request errors and Retry. Do not fill space with fake cards or pending/ineligible submissions.

Keep saved logos contained without cropping or stretching. Preserve capability checks, server fields, vote/comment counts, score release, pagination and canonical existing project routes. Sharing is handled separately. No animation dependency, new request or new image artwork is needed.
